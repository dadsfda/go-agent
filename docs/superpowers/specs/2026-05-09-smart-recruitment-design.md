# 智能招聘系统设计说明

## 目标

基于 PRD 实现一个可本地演示的智能招聘系统，覆盖 HR 管理端、候选人端、Gin Web 网关、Logic gRPC 服务、数据模型文档、接口文档和启动说明。

## 架构

系统按作业要求拆成四个工程：`hr-frontend`、`user-frontend`、`web-gin-service`、`logic-grpc-service`。前端只负责页面、交互和 HTTP 请求；Gin Web 服务负责 HTTP 接入、跨域、JWT 鉴权和参数校验；Logic 服务承载账号、岗位、档案、简历、投递、AI 问答等核心业务能力。Web 与 Logic 之间只通过 gRPC 通信。

为了保证本机没有 MySQL、OSS、Eino 密钥时也能演示主流程，Logic 服务默认使用内存仓库；配置 `MYSQL_DSN` 后可切换为 MySQL 仓库扩展点。OSS 与 Eino 均保留真实配置入口，本地演示时返回可解释的模拟签名 URL 与基于业务数据的问答结果。

## 功能边界

本期实现 P0 主流程：双角色注册登录、JWT、岗位浏览、候选人档案、简历格式校验、简历记录、岗位投递、HR 岗位管理、投递台账、AI 业务问答和对话历史。简历解析自动填充作为 P2 可选能力，仅在文档和接口预留说明，不阻塞核心验收。

## 测试与验证

后端核心业务采用 Go 单元测试覆盖权限、投递校验、简历格式校验和 AI 问答数据来源。完成后运行 `go test ./...` 验证两个后端工程，前端使用静态文件人工打开或本地服务查看。
